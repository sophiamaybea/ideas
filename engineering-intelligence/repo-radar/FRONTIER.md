# Frontier Radar

Initial live scan: 2026-10-07.

## High-interest watchlist

### `ruvnet/ruflo`
Agent harness / swarm orchestration with adaptive memory and self-learning claims. ~74k stars and pushed 2026-10-07. Important because it overlaps heavily with our intended multi-agent runtime. Inspect architecture before borrowing concepts; high scope means high integration risk.

### `Yeachan-Heo/oh-my-claudecode`
Teams-first multi-agent orchestration for Claude Code. Created in 2026, ~39.6k stars, pushed 2026-10-07. Study parallel execution, team decomposition and coding-agent coordination patterns.

### `VRSEN/agency-swarm`
Multi-agent orchestration. ~4.6k stars, pushed 2026-10-07. Potentially useful as a simpler reference for role/tool topology.

### `nottelabs/notte`
Cloud browser infrastructure and web automation for AI/coding agents. ~2k stars, active. Useful comparison against Browser Use where remote browser/session infrastructure is needed. Licence currently needs careful review.

### `doobidoo/mcp-memory-service`
Persistent memory, REST/MCP, knowledge graph and consolidation. ~2k stars, Apache-2.0, active. Interesting as a self-contained memory service rather than embedding memory inside every agent.
