# Engineering Intelligence

A living research-and-engineering memory for the systems we are inventing.

This is not an "awesome list". Its job is to convert new technology, GitHub activity, experiments and our own conversations into reusable capability, product architecture and economic decisions.

## Core loop

```
recent work + market evidence + GitHub changes
                ↓
          extract claims
                ↓
     repo / technology archaeology
                ↓
       capability primitives
                ↓
  missing abstractions + combinations
                ↓
    product / business implications
                ↓
 Wolfram modelling + optimisation
                ↓
   build / test / kill / scale
                ↓
          outcome memory
```

## Knowledge rules

1. Separate **FACT / EVIDENCE / INFERENCE / HYPOTHESIS / SPECULATION**.
2. Prefer primary sources, executable code and observed outcomes.
3. GitHub is reasoning infrastructure, not an appendix.
4. Record what a repository enables, not merely what it claims.
5. Never confuse stars with engineering quality.
6. Track licence, activity, architecture, dependencies, security, composability and maintenance risk.
7. Preserve failed ideas and rejected repos so the system does not repeat work.
8. Every important discovery should answer: **what can we build now that was harder yesterday?**
9. Use open-source/local/free infrastructure first. Spend money only when earned value justifies it.
10. Keep humans in the loop for consequential financial, legal, security, identity or irreversible actions.

## Current thesis

The highest-leverage direction is an **Autonomous Economic Agent Runtime**: a system that discovers economic opportunities, compiles missing capabilities from open-source technology, launches bounded experiments/businesses, executes work, measures actual profit and learning, reallocates resources and kills weak ventures. Wolfram acts as the quantitative decision layer rather than the universal execution engine.

Related systems such as Money Radar, the AI Business Command Centre, GitHub Archaeology, the Wolfram Super-Stack and the Product Reconstruction Engine become modules of the same larger machine.
