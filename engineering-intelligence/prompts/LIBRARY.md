## Preservation rule

For every substantial prompt created from this point forward, the hourly collector should store:
1. title;
2. full prompt text where retrievable;
3. slash-mode aliases;
4. purpose;
5. inputs/outputs;
6. parent prompt(s);
7. changes from earlier versions;
8. projects that used it;
9. observed outcome if tested.

The initial pre-dashboard entries are indexed faithfully from available recent-chat context; full verbatim text was not retrievable for every earlier item, so they must not be falsely labelled as verbatim.
