# Engineering Intelligence Dashboard

Static Vercel frontend for the living engineering-intelligence branch.

## Data model
The interface attempts to fetch the live hourly dataset from:
`engineering-intelligence/dashboard/data/dashboard.json` on the `engineering-intelligence` branch.

A deployment-local snapshot is bundled as a fallback.

## Views
- NOW
- REPOS
- PROMPTS
- VENTURES
- COMPANIES
- CURRENT
- LEARNING

The design is intentionally high-contrast, typography-led and low-chrome. Predicted financial outputs are visually separated from observed revenue.
