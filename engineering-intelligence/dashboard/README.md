# Engineering Intelligence Dashboard

Static Vercel front end for the `engineering-intelligence` branch.

The **Money Signals** view is backed by an hourly collector that scans public Reddit, GitHub and Hacker News signals, normalises them, deduplicates them and scores them for evidence strength. Concrete payer + workflow + recurring economics outrank vague income claims. GitHub repositories are treated as build signals, not proof of revenue.

The collector does not bypass authentication, CAPTCHAs or access controls.
