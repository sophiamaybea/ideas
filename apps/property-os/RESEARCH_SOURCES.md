# Open-source research & property integrations

The attached **GitHub for research.txt** lists a research process:

`question → split → search → extract → link claims → cross-check → cite → report`

This proof-of-concept includes a *research capability library* of links and editable local research notes. **No external engines are running.** Each external project's documentation, licences, security requirements and deployment assumptions must be assessed before integration.
